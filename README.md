# CRIATURIX · Futurmovil

Juego de criaturas robot por cartas (cría, combate, mercado).

- Frontend: GitHub Pages (`index.html`, `style.css`, `game.js`, `combate.js`, `admin.js`, `js/datos.js`, `js/robot.js`). PWA.
- Backend: Apps Script «criaturix» (`apps-script/Code.gs`, `Datos.gs` = `js/datos.js`, `Motor.gs` = `js/motor.js`) + Google Sheet «criaturix».
- Pagos con myPOS (https://mypos.com/@futurmovil/IMPORTE). El admin confirma el pago en el panel; el vendedor recibe el % de comisión en créditos.
- Panel admin: mantener ENTRAR 3 s, 10 toques al logo, o botón en Inicio (cuenta futurmovil.com@gmail.com). Llave NFC, QR para el PC o Google Authenticator.
